Node.js Microservices

A Node.js and TypeScript microservices application using an API Gateway to route requests between different services.

Services

- API Gateway
- Task Service
- Workflow Service
- Media Service

Tech Stack

Node.js, TypeScript, Express.js, Docker

Installation

npm install

Environment Variables

Create a ".env" file and add the required service URLs and configuration.

Run

npm run dev

The API Gateway receives client requests and routes them to the appropriate microservice.
